# 网易云备用音源

入口：**设置 → 在线 → 备用音源**。一个总开关统一控制 GD Studio 与 UnblockNeteaseMusic。

- 支持任意多选，上移、下移决定尝试顺序，可以交错排列两种服务的来源。
- **GD · Netease 默认勾选且排在第一位**；其余 GD 来源默认关闭。已有的总开关禁用状态和 Unblock 来源选择会保留。
- GD 提供 Netease、JOOX、Bilibili、QQ Music、Kuwo、TIDAL、Qobuz、Apple Music、YouTube Music、Spotify；Unblock 提供 Kugou、Bodian、Kuwo。
- GD 与 Unblock 的 Kuwo 是不同取址服务，分开选择、排序和缓存。
- 允许全部取消勾选；关闭总开关不会清空选择和顺序。重新启动后保留设置。

建议先启用少量常用来源，例如 GD Netease、GD JOOX、GD Bilibili、Unblock Kugou、Unblock Kuwo，按自己实际可用性排序。GD 文档标记前三个平台较稳定，其余平台可能不可用。启用更多来源会增加全部失败时的等待时间，不保证一定能匹配到歌曲。

播放默认先请求网易云官方音源；官方返回试听、无版权、订阅限制或空地址时尝试备用来源。登录错误与官方 API 网络错误继续如实报告。已经取到地址但下载失败时，会跳过这个来源继续尝试，单次流程不会重复尝试同一个配置项。下载可选择官方优先或备用优先，备用优先也使用这里的完整排序。取消操作会停止后续尝试。

此配置用于网易云播放与网易云下载入口；**在线搜索的直接 GD 下载**仍使用搜索结果自身的平台及“在线搜索”音质设置。

GD Netease 使用原网易云歌曲 ID；其他 GD 平台先搜索歌名与歌手，保守核对歌名、歌手集合和版本词，有多个候选时用专辑消歧。无法确定时跳过，取址使用匹配平台返回的 ID。GD 搜索接口没有文档化的时长字段，不能假定已校验时长。GD 搜索、取址、图片共享每 5 分钟 50 次请求预算；遇到 GD 限流后，本轮跳过剩余 GD 来源，仍可尝试 Unblock。

GD 备用音质和 Unblock 无损偏好分别配置。实际音质以服务返回为准。Unblock 辅助进程只在需要时启动；取消全部 Unblock 来源、关闭总开关或修改其音质后停止旧进程，下次需要时重新启动。

配置保存在应用数据目录的 `AudioFallback.json`，与 `Settings.xml` 同级，Portable 模式随程序数据目录保存。写入采用临时文件加原子替换，写入成功才更新生效状态；失败会在界面提示。配置损坏或版本不支持时关闭备用调用并保留原文件；备份该文件并修复或移走后重新启动即可重新迁移默认值。不会写入音频 URL、Cookie 或凭证。

回归覆盖：13 个来源注册、GD 默认顺序、旧设置迁移、5 个来源交错排序与保存恢复、空选择、总开关、写入失败回滚、跨平台 ID 与版本匹配、限流、取消和失败来源排除。完整 WPF 编译、NUnit 测试与 Portable 启动检查由 GitHub Actions 执行。
